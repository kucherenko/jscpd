# Examples

| Directory | What it shows |
|-----------|---------------|
| [`rust-cpd-finder/`](rust-cpd-finder) | Embedding the engine through the [`cpd-finder`](https://crates.io/crates/cpd-finder) crate: configure a run, execute it, and read the clones and statistics. |

For the CLI, the GitHub Action, Docker image, and pre-commit hooks see the [documentation](https://jscpd.dev) and [`docs/`](../docs).

Node.js API examples (`jscpd()`, `detectClones()`, LevelDB store) belong to jscpd v4 and live in `examples/api/` on the [`master-v4`](https://github.com/kucherenko/jscpd/tree/master-v4/examples/api) branch.
